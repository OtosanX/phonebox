# PhoneBox Spellbook

Use an Android touchscreen as a customizable control panel for World of Warcraft Forever on Windows. Pick actions from your character’s current spellbook and put them into folders on your PhoneBox deck.

- Add learned spells, existing macros, usable inventory items and available pet actions through the PhoneBox web editor.
- Organize form-specific actions in subfolders. For supported stealth states, the deck can switch to the stealth actions when the in-game state changes.
- Use Adventure for your detected Hearthstone and fishing setup, plus Food & Drink, Potions, and Pets. Pets lists collected Pet Journal companions. Hunters also get a separate Hunter Pet folder for active combat-pet commands.
- Use game icons where available. Every cast or item use requires a separate deliberate tap. WoW applies its normal rules for combat, forms, targeting and cooldowns.

## Requirements

This add-on targets **WoW Forever 1.60.1**. The separate **PhoneBox WoW companion for Windows 11** and **PhoneBox Android app** are required for the touchscreen. The Windows companion reads the action list locally from the add-on’s SavedVariables. The add-on also displays a small on-screen indicator for supported stealth states.

## Setup

1. Install PhoneBox Spellbook for WoW Forever and start the Windows and Android companions.
2. Log in to a character. Outside combat, type `/pbspells` in WoW to refresh and save the action list.
3. Open the PhoneBox settings in your PC browser at `http://127.0.0.1:8765`. In the WoW deck, open **WoW Actions** and use **Choose actions** to pick the buttons to show.
4. Return focus to the game before using the deck.
